# Тренажер з математики

Простий сайт із вправами з математики дошкільного рівня для роботи на планшеті разом з асистентом учителя.
Працює в Chrome (Android) і Safari (iPad), у горизонтальній і вертикальній орієнтації. Після першого відкриття працює й без інтернету.

Сайт публічний, тому в ньому немає жодних імен чи особистих даних. Журнал зберігається лише на самому планшеті.

## Як користуватися (для асистента)

1. Відкрийте сайт на планшеті. Порада: додайте його на головний екран («Поділитися» → «На екран “Додому”» на iPad або «⋮» → «Додати на головний екран» в Android).
2. У меню торкніться картинки вправи. Дрібні підписи під картинками — для вас.
3. Угорі великим текстом — інструкція. Прочитайте її учневі вголос. Звуку на сайті немає.
4. Учень відповідає дотиком:
   - **правильно** — зелена рамка, за 1 секунду наступне завдання;
   - **неправильно** — кнопка легенько хитається, а правильна відповідь м'яко підсвічується жовтим. Без хрестиків і без «помилок»: просто покажіть на підсвічене.
5. Після 5 завдань з'являються зірочки й «Молодець!». Торкніться 🏠, щоб повернутися в меню.
6. Кнопка 🏠 угорі зліва будь-коли повертає в меню.

### Вправи

| Вправа | Що робить учень |
|---|---|
| Порахуй | Торкається кожного олівця (на ньому з'являється номер), потім вибирає число. |
| Яку цифру сховали? | Дивиться на ряд цифр, одна закрита хмаринкою, вибирає її. |
| Покажи фігуру | Показує названу фігуру: трикутник, квадрат, прямокутник, коло. |
| Де більше? | Показує тарілку, де більше / менше. Останнє завдання — «Порівну?» (👍 / 👎). |
| Дай стільки ж | Перекладає яблука з коробки на порожню тарілку (повторний дотик повертає назад), потім «Готово». Якщо кількість інша, сайт показує «Порахуймо разом» і нумерує яблука на обох тарілках по черзі. |
| Знайди цифру | Показує названу цифру серед карток. |
| Скільки кутів? | Торкається кожного кута (з'являється зірочка з номером), потім вибирає 3 чи 4. |

### Режим асистента

Натисніть і **утримуйте 2 секунди** шестерню ⚙️ у правому верхньому куті меню. Звичайний дотик її не відкриває, щоб учень не потрапив туди випадково.

- **Налаштування для кожної вправи:**
  - *Діапазон* — числа до 5 чи до 10.
  - *Варіантів* — скільки карток на вибір: 2, 3 або 4.

  Прочерк означає, що для цієї вправи налаштування не діє.
- **Журнал:** дата, вправа, скільки завдань учень зробив з першої спроби і скільки — з підказкою. Записується після кожної завершеної вправи (5 завдань).
  - «Завантажити CSV» — файл, який відкривається в Excel або Google Таблицях.
  - «Очистити журнал» — видаляє всі записи (з підтвердженням).

Журнал і налаштування зберігаються лише в браузері цього планшета. Якщо очистити дані браузера, вони зникнуть.

## Як оновити сайт

Сайт — це звичайні файли в репозиторії GitHub. Після кожної зміни в гілці `main` GitHub Pages сам оновлює сайт приблизно за 1–2 хвилини.

**Через браузер:** відкрийте файл на GitHub → ✏️ (Edit) → внесіть зміни → «Commit changes».

**Через комп'ютер:**

```bash
git clone https://github.com/<ваш-акаунт>/math-trenazher.git
cd math-trenazher
# змініть файли
git add -A
git commit -m "Опис змін"
git push
```

На планшеті нова версія з'явиться, якщо відкрити сайт з інтернетом **двічі**: перший раз сайт тихо завантажує оновлення, другий раз показує його.
Якщо додали новий файл (наприклад, нову вправу в `games/`), допишіть його ще й у список `FILES` у `sw.js`, щоб він працював офлайн.

## Будова

```
index.html     екрани: меню, вправа, нагорода, режим асистента
style.css      вигляд
app.js         спільна логіка: хід вправи (5 завдань), підказки, нагорода, налаштування, журнал
games/*.js     по одному файлу на вправу
sw.js          робота без інтернету
```

Без фреймворків і збірки: щоб перевірити зміни на комп'ютері, достатньо запустити в папці `python3 -m http.server` і відкрити http://localhost:8000.
