# Тренажер з математики

Простий сайт із вправами з математики дошкільного рівня для роботи на планшеті разом з асистентом учителя.
Працює в Chrome (Android) і Safari (iPad), у горизонтальній і вертикальній орієнтації. Після першого відкриття працює й без інтернету.

Сайт публічний, тому в ньому немає жодних імен чи особистих даних. Журнал зберігається лише на самому планшеті.

## Як користуватися (для асистента)

1. Відкрийте сайт на планшеті. Порада: додайте його на головний екран («Поділитися» → «На екран “Додому”» на iPad або «⋮» → «Додати на головний екран» в Android).
2. У меню торкніться картинки вправи. Дрібні підписи під картинками — для вас.
3. Угорі великим текстом — інструкція. Планшет промовляє її голосом (якщо голос увімкнено), рахує вголос і хвалить «Молодець!». Кнопка 🔊 «Ще раз» повторює інструкцію. Якщо голос вимкнено — прочитайте інструкцію учневі самі.
4. Учень відповідає дотиком:
   - **правильно** — зелена рамка, за 1 секунду наступне завдання;
   - **неправильно** — кнопка легенько хитається і зникає. Правильна відповідь **не** підказується: якщо в завданні є що рахувати, з'являється «Порахуймо разом» і предмети по черзі отримують номери 1, 2, 3… Після цього учень вибирає ще раз сам. Під час лічби дотики ігноруються. Так вгадувати стає довше, ніж порахувати.
5. За кожне завдання — зірочка: **золота**, якщо з першої спроби, **сіра**, якщо була помилка. Прогрес видно вгорі (жовті й сірі крапки).
   У вправах на додавання й віднімання замість крапок — **ракета**: кожне завдання додає деталь (кольорову або сіру). Якщо всі 5 з першої спроби — ракета злітає на екрані нагороди.
6. Після 5 завдань — екран нагороди: зірочки, «Молодець!» і **скарбничка**. Золоті зірочки накопичуються між вправами; кожні **5 золотих** дають **нову наліпку**. Торкніться 🏠, щоб повернутися в меню.
   Усі зібрані наліпки — в «Альбомі наліпок» (📒 угорі меню). В альбомі 4 сторінки по 30 наліпок: Тварини → Транспорт → Смаколики → Небо і космос. Наступна сторінка відкривається, коли попередню зібрано повністю.
7. Кнопка 🏠 угорі зліва будь-коли повертає в меню.

### Вправи

| Вправа | Що робить учень |
|---|---|
| Порахуй | Торкається кожного предмета (на ньому з'являється номер), потім вибирає число. |
| Яку цифру сховали? | Дивиться на ряд цифр, одна закрита хмаринкою, вибирає її. |
| Покажи фігуру | Показує названу фігуру: трикутник, квадрат, прямокутник, коло. |
| Де більше? | Показує тарілку, де більше / менше. Останнє завдання — «Порівну?» (👍 / 👎). |
| Дай стільки ж | Перекладає яблука з коробки на порожню тарілку (повторний дотик повертає назад), потім «Готово». Якщо кількість інша, сайт показує «Порахуймо разом» і нумерує яблука на обох тарілках по черзі. |
| Знайди цифру | Показує названу цифру серед карток. |
| Скільки кутів? | Торкається кожного кута (з'являється зірочка з номером), потім вибирає 3 чи 4. |
| Нагодуй тваринку | Тваринка «просить» їжу: у хмаринці цифра і стільки ж смаколиків. Учень кладе стільки ж у мисочку, потім «Готово». |
| Скільки тут? | Дивиться на групу предметів і вибирає цифру (без перелічування дотиком). |
| Знайди стільки ж | Бачить цифру і вибирає картку, де стільки ж предметів. |
| Великий і маленький | Показує великого або маленького звірка (по черзі). |
| **Числа до 15** | |
| Десяток і ще | Бачить повну рамку на 10 і ще 1–5 предметів, вибирає 11–15. Підпис «10 і ще 3» підказує, як складається число. |
| Сусіди числа | На числовому ряді виділено число. «Яке число після 7?» (перші 3 завдання), потім «Яке число перед 7?». |
| **Додавання і віднімання** | |
| Разом | Перекладає предмети з двох тарілок в один кошик (кожен отримує номер), потім вибирає, скільки разом. Унизу приклад 3 + 2 = 5. |
| Скільки залишилось? | «Забери 2» — торкається двох предметів, вони бліднуть. Потім вибирає, скільки залишилось. Унизу приклад 5 − 2 = 3. |
| Приклад з картинкою | Приклад 3 + 2 = ? (завдання чергуються з відніманням), під числами предмети. Картинки можна вимкнути в налаштуваннях. |
| Розклади число | Торкається будиночків, щоб поселити звірків. Будь-який розподіл правильний; наприкінці видно 5 = 2 + 3. |

У кожному завданні — новий набір предметів: тварини, фрукти, цукерки, кульки, машинки тощо. Це допомагає тримати увагу.

### Режим асистента

Натисніть і **утримуйте 2 секунди** шестерню ⚙️ у правому верхньому куті меню. Звичайний дотик її не відкриває, щоб учень не потрапив туди випадково.

- **Голос:** увімк. / вимк. для всіх вправ. Під перемикачем видно, чи є на планшеті український голос.
  Якщо його немає — сайт мовчить і показує лише текст. Додати голос:
  - **Android:** Налаштування → Спеціальні можливості → Синтез мовлення → Google → встановити голос «Українська».
  - **iPad:** Параметри → Доступність → Вміст мовлення → Голоси → Українська.

- **Налаштування для кожної вправи:**
  - *Діапазон* — числа до 5, до 10 або (для деяких вправ) до 15.
  - *Варіантів* — скільки карток на вибір: 2, 3 або 4.
  - *Картинки* — для «Приклад з картинкою»: показувати предмети під числами чи лише цифри.

  Прочерк означає, що для цієї вправи налаштування не діє.
- **Журнал:** дата, вправа, скільки завдань учень зробив з першої спроби і скільки — з підказкою. Записується після кожної завершеної вправи (5 завдань).
  - «Завантажити CSV» — файл, який відкривається в Excel або Google Таблицях.
  - «Очистити журнал» — видаляє всі записи (з підтвердженням).
  - «Почати альбом заново» — прибирає всі зібрані наліпки (золоті зірочки в скарбничці лишаються).

Журнал, наліпки й налаштування зберігаються лише в браузері цього планшета. Якщо очистити дані браузера, вони зникнуть.

## Як оновити сайт

Сайт — це звичайні файли в репозиторії GitHub. Після кожної зміни в гілці `main` GitHub Pages сам оновлює сайт приблизно за 1–2 хвилини.

**Через браузер:** відкрийте файл на GitHub → ✏️ (Edit) → внесіть зміни → «Commit changes».

**Через комп'ютер:**

```bash
git clone https://github.com/<ваш-акаунт>/math-trenazher.git
cd math-trenazher
# змініть файли
git add -A
git commit -m "Опис змін"
git push
```

На планшеті нова версія з'явиться, якщо відкрити сайт з інтернетом **двічі**: перший раз сайт тихо завантажує оновлення, другий раз показує його.
Якщо додали новий файл (наприклад, нову вправу в `games/`), допишіть його ще й у список `FILES` у `sw.js`, щоб він працював офлайн.

## Будова

```
index.html     екрани: меню, вправа, нагорода, режим асистента
style.css      вигляд
app.js         спільна логіка: хід вправи (5 завдань), підказки, нагорода, налаштування, журнал
games/*.js     по одному файлу на вправу
sw.js          робота без інтернету
```

Без фреймворків і збірки: щоб перевірити зміни на комп'ютері, достатньо запустити в папці `python3 -m http.server` і відкрити http://localhost:8000.
